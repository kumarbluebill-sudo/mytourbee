# My TourBee

Static travel website (HTML/CSS/JS). No build step required.

## Structure
```
index.html
css/style.css
js/main.js
images/          <- put logo.png, golden-triangle.jpg, kerala.jpg, goa.jpg,
                    rajasthan.jpg, thailand.jpg, bali.jpg, europe.jpg, dubai.jpg
vercel.json
```

## Deploy
**GitHub Pages:** push -> Settings > Pages > Deploy from branch `main` / root.
**Vercel:** Import the repo -> Framework Preset: Other -> leave build/output blank -> Deploy.
